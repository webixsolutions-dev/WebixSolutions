# 04 — Page briefs: industry pages

Industry pages exist only where we can say something specific. Each page follows the service template (see `03`) with these changes: hero names the industry's main pain; "Outcomes" becomes "What usually goes wrong"; "What's included" becomes "What we set up for [industry]"; proof must be from that industry if we have it.
