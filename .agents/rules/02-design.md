# Rule 02 — Signal design system

See `docs/05-design-system.md` for tokens, component rules and verification.

- Use logo red, near-black and white. Use Signal Ink for small white-on-red controls and Ember for small red text on dark. Use body text that meets 4.5:1 contrast.
- Cards have 14px corners and use surface contrast. Hover lifts 4px with a 2px Signal Red ring. Large showcase media and booking can use the large opposite-corner chamfer. Sections have straight edges.
- Buttons and fields use 10px corners, chips are pills, and the design uses Clash Grotesk and Switzer. Use sentence case and up to three kickers per page.
- Only the hero and globe use faint grain and pointer light. Prefer whitespace and subtle dividers.
- Use Lenis for fine pointers, keep native touch momentum, and honor reduced motion. Use GSAP for selected scroll effects and Motion for component interactions. Keep meaningful content in the initial HTML.
- Verify keyboard operation, 44px targets, visible focus and layouts at 390, 768 and 1440 px before review.
